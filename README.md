## ◈ About

I am a software engineer focused on building scalable backend systems, intelligent applications, and production-grade computer vision products. My core is Python — I architect FastAPI-powered REST services with clean separation of concerns, authentication systems, and database design using PostgreSQL and Firebase.

On the AI/ML side, I actively work with PyTorch, TensorFlow, and OpenCV — building real-time computer vision systems such as PPE detection and fire & smoke detection pipelines. My focus is not just models, but deploying them into usable, real-world safety systems.

I think of AI as an engineering primitive, not a demo layer — something that must run reliably in production environments.
